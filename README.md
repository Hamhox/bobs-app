# Bob's App

Bob's App is the public index for small applications and project case studies. The first release is a static Hello World page that verifies the GitHub-to-Vercel deployment path before the project grows.

## Local preview

Serve the repository root with any static file server. For example:

```powershell
npx serve .
```

## Deployment

Vercel serves `index.html` from the repository root. No build command or runtime environment variables are required for this release.
