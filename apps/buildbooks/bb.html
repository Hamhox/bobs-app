Click on the label preview image above, select 'Print' in the browser menu, or press ctrl-P or ctrl-shift-P.

To print, you must have the printer added to Windows on your computer through USB or the network. Press the Windows key and type 'printers' to open the Printers & Scanners Windows screen. Make sure the printer is showing, try to print a test page.

Setup printer options, or the print will not fill the label:

  • Page height: 1"
  • Page width: 3.5"
  • Offset Top: 0.1"
  • Offset Left: 0.05"
  • Do NOT Shrink Page to Fit
  • Scale: 100%
  • Margins: 0
  • Headers and Footers: --blank--

Depending, these may be found in Windows 'printing preferences' and the browser 'page setup.'

The system should remember printing preferences. If not, try these things:

  • Set preferences directly. Press the Windows key and type 'printers' to open the Printers & Scanners Windows screen. Click 'Manage' then 'Printing Preferences.' Set the preferences here to definitely save them.
  • If using Firefox, type 'about:config' in the address bar. Scroll down and click the 'Clear saved print settings' button. Reboot Firefox. Try to print the label by using the Firefox menu, making sure to set the page height settings. The new settings should now be saved each time printing is tried.

See 'Printer Preferences' above. Preferences are critical to the print being properly aligned on the label.

The labels are known to print in Chrome 87.0.4280.88 and Firefox 83.0 on a Zebra ZT410 printer. Buildbooks does not work in Internet Explorer.
